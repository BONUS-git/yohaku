# 地図

知りたいこと → 図 → 文書の節。毎回すべての文書を読み直さず、ここが指すところだけを読む。

## 知りたいこと

| 知りたいこと | 図 | 文書の節 |
|---|---|---|
| 構想の原文 | なし | `.ai/brief.md` |
| 何を作るか（FR・NFR） | なし | `.ai/requirements.md` の「機能要件」「非機能要件」 |
| 構想の節と FR の対応 | なし | `.ai/brief-map.md` |
| M1（MVP）の範囲と完了の目安 | `.ai/diagrams/roadmap.md` | `.ai/mvp.md` の「M1 に入れる FR」「M1 の完了の目安」 |
| 段階ごとの FR・依存・受け入れ条件 | `.ai/diagrams/roadmap.md` | `.ai/roadmap.md` の「M ごとの FR」と各 M の節 |
| M1 の外に持ち越すもの・未確定のもの | `.ai/diagrams/roadmap.md` | `.ai/gaps.md` |
| マスターに聞いたこと・決まったこと | なし | `.ai/open-questions.md` |
| 設計判断 | なし | `.ai/adr/README.md`・`.ai/adr/0001-no-save-without-amount.md` |
| 進捗 | なし | `.ai/status.md`（秘書が書く） |
| `.ai/` の文書の役目 | なし | `.ai/README.md` |
