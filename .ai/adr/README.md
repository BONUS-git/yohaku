# ADR（設計判断の記録）

1 つの判断を 1 つのファイルに: `NNNN-<題>.md`（NNNN は 0001 からの連番）。

ADR は 1 つに決定 1 つ、題は 40 字まで。前の決定を変えるときは新しい ADR を作り、古い ADR の状態を `置き換え（→ NNNN）` にする。状態は `提案`・`採用`・`置き換え（→ NNNN）` のどれか 1 行だけ（どの項を変えたかの注記を重ねない。一部だけ変わるなら、残る決定も新しい ADR に書いて丸ごと置き換える）。

```markdown
# NNNN — <題>

- 状態: 採用
- 日付: YYYY-MM-DD

## 背景
## 決定
## 理由
## 代わりの案（選ばなかった理由）
## 影響
```
